## EC2

**Supported Events**:

- RunInstances: launches instances using a specificed AMI
- StartInstance: starts a stopped instance
- CreateImage: creates an AMI from an instance with EBS volume
- CreateSnapshot: creates a snapshot of an EBS volume and stores in S3
- CreateSnapshots: creates snapshots of multiple EBS volumes and stores in S3
- CreateInteretGateway: creates an IGW
- CreateFlowLogs: create VPC flow logs
- CreateFleet: create a fleet of on-demand and spot instances
- RequestSpotFleet: deprecated
- RequestSpotInstances: deprecated
- CreateNatGateway: create a managed NAT instance
- CreateStoreImageTask: store an AMI to S3 bucket
